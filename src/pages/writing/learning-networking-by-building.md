## Build the mental model

Networking becomes easier when concepts stop being diagrams and start becoming packets, ports, routes, sockets, and failures you can observe.

## The loop

Read a concept. Reproduce it locally. Break it deliberately. Inspect what happened. Write the lesson down.

That loop is becoming my default way to study systems.
